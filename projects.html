G-boy: 9V Simple Videogame Console

I built and soldered a handheld game console using a custom manufactured PCB and an Arduino UNO. The console runs games that I coded myself and displays them on a 16×2 LCD screen interfaced in 8-bit mode. The entire system is powered by a 9V battery, making it portable. This project taught me about PCB design, LCD interfacing protocols, and programming for embedded systems. It was challenging to get the timing right for the LCD communication and optimize the game code to run smoothly on the Arduino.

Battery Powered Blinking Lightbox

I created a custom lightbox using an RGB LED strip connected to a custom designed and soldered PCB. The system is powered by a 9V battery, making it completely portable. I designed the PCB layout to handle the LED strip control and power management. The project involved learning about LED driver circuits, power consumption considerations for battery powered devices, and proper soldering techniques for PCB assembly. It was interesting to work out how to efficiently drive multiple LEDs while keeping the power draw low enough for battery operation.

Wall-Mounted Modular Hydroponic Tower

This project is a work in progress that combines my interest in engineering design with sustainable urban gardening. I'm designing a wall-mounted modular planter system inspired by vertical hydroponic towers, but redesigned to be modular and customizable for small spaces like balconies or classrooms. The system uses cylindrical segments that can be attached side-by-side or stacked. Each segment holds interchangeable planting pods. The water flow system incorporates Tesla valve inspired channels that allow water to drain efficiently downward while resisting reverse flow and evaporation. I'm using 3D printing to prototype the modular components, Tesla valve channels, and mounting systems. This project involves learning about fluid dynamics principles, modular design, and material selection for outdoor use.
