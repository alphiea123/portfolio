HAVS Grip Tracker

PiD Labs · Undergraduate Lead Researcher · Summer 2026

I led a URI Provost summer research project on measuring grip force on vibrating power tools, work aimed at understanding and reducing Hand-Arm Vibration Syndrome (HAVS). I designed 3D-printed drill handle covers in Onshape with a 0.8 mm clearance gap so force-sensitive resistors would not pinch at rest and create a false baseline. On the electronics side I filtered EMI on analog sensor lines (about 15 dB lower noise floor) and wrote C++ firmware on an Arduino Mega 2560 for ~100 Hz sampling, I2C OLED telemetry, and a 5-second static-grip safety alarm. Four FSRs sit under rigid actuator pucks on the handle; the display shows per-sensor and total load, and flags a static grip if force stays above threshold without enough change. Findings were presented at the NJIT Summer Research Symposium 2026. This work was supported by the URI Provost Fellowship, ISOTOPE, and HSRI funding.

Jackhammer Simulator for Telerehabilitation

PiD Labs · Undergraduate Research Assistant · 2025–2026

On a 4-person multidisciplinary team I helped build a robotic jackhammer simulator for task-oriented telerehabilitation, advised by Dr. Roni Barak Ventura. The idea is a safe, sensor-integrated stand-in for a real jackhammer so injured construction workers can retrain grip, posture, and vibration tolerance without clinic-only therapy. I drafted KiCad schematics and custom component symbols, then built and debugged breadboard and screw-terminal prototypes tying a microcontroller to HX711 load-cell modules, motor drivers, and an I2C 1602 LCD. A locomotive-style crank converts rotary motor motion into a reciprocating bit, which is what the animation on the left shows. The team secured and managed $3,000+ in project funding for this work.

Automated Python Hardware Test Suite

Personal / lab tooling · 2026

I built a Python (PySerial) script that reads microcontroller data over UART at 9600 baud and runs automatic pass/fail voltage checks in a 3.0 V to 3.6 V window. Over 100 continuous test runs, that cut manual testing time by about 85%. Results are written straight to CSV with live VPython graphs so the same log can be opened in Excel for later analysis.

G-boy: 9V Simple Videogame Console

Personal hardware project · 2024

I built and soldered a handheld game console using a custom manufactured PCB and an Arduino UNO. The console runs games that I coded myself and displays them on a 16×2 LCD screen interfaced in 8-bit mode. I hand-soldered 40+ SMD and through-hole parts and used a 16-channel logic analyzer to fix display timing bugs across 9 game modes. The whole system runs from a 9V battery.

Wall-Mounted Modular Hydroponic Tower

This project is a work in progress that combines engineering design with sustainable urban gardening. I'm designing a wall-mounted modular planter system inspired by vertical hydroponic towers, redesigned to be modular for small spaces. Cylindrical segments can attach side-by-side or stack, and Tesla-valve-inspired channels let water drain downward while resisting reverse flow. I'm using 3D printing to prototype the modules and mounts.
